# 3D example geometry

Small mesh files for trying the 3D import and for the tests (`tests/test_geometry3d_*.py`).
All of them are generated by `make_examples.py` (no third-party models); run it again to
rebuild them:

```
python examples/geometry3d/make_examples.py
```

| file | what it exercises |
|---|---|
| `sphere_d100mm_binary.stl` | binary STL; a 100 mm sphere stored in millimetres, so the units guess says "mm" |
| `box_and_cylinder_ascii.stl` | ASCII STL with two `solid` blocks, read as two meshes (metres) |
| `body_and_wheel.obj` | OBJ with two groups, `body` (written as quads, fan-triangulated on import) and `wheel` (negative indices, `v/vt/vn` triples) |
| `wedge_binary.ply` | binary little-endian PLY with quads and triangles mixed, a per-vertex colour and an extra element the reader skips |
| `leaky_sphere.stl` | a 1 m sphere with a patch of triangles missing (a hole of about 20 degrees): not watertight, yet it voxelises like the closed sphere (the hole is closed flat across its rim) |

What the importer does with them, in Python:

```python
import aerolume.geometry3d as G

meshes = G.read_mesh("examples/geometry3d/body_and_wheel.obj", units="auto")
design = G.design_from_meshes(meshes, "Sample", "vehicle")
print(design.ref_area, design.length_ref, design.symmetric)
print(G.check_design3d(design, cells_per_ref=48))
```
